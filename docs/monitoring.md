# Мониторинг ресурсов Orbit

Вкладка «Настройки → Мониторинг» запрашивает приватный API
`GET /api/system/resources/`. Процессы, память и CPU измеряются отдельно от
размеров файлов; свободное место читается заново при каждом запросе.

Полный обход каталогов профилей может занимать несколько минут. Он выполняется
в фоне одним общим для запросов сканированием с ограничением 10 минут.
Доступные категории выдаются постепенно; неизвестный размер не равен нулю.
`disk.bytes` содержит полный итог только после успешного обхода, `knownBytes` —
объём уже измеренных категорий. `scanState` различает `scanning`, `idle`, `error`.
При повторном сканировании сохраняется последний полный результат и его время.

Успешный размер кэшируется на 5 минут, неполный замер повторяется через 30 секунд.
`?refresh=1` запускает досрочную проверку, не создавая второй параллельный обход.
Событие очистки релизов также инициирует перерасчёт. При открытой вкладке
результат текущего сканирования запрашивается каждые 3 секунды; в обычном режиме —
каждые 30 секунд. Нагрузка кэшируется на 15 секунд. Скрытая вкладка не опрашивает API.

Размеры на диске измеряются по выделенным блокам `du`, без перехода по симлинкам
и без повторного учёта hardlink-файлов внутри каждого дерева. Вложенные каталоги
приложения и данных не складываются дважды. Интерфейс использует двоичные
единицы КиБ/МиБ/ГиБ/ТиБ, согласованные с обычным `df -h`.
Процент заполнения считается от занятого и доступного объёма, с округлением
вверх, как у `df`; резерв файловой системы показывается отдельно.

Время измерения размеров и нагрузки различается. Размеры не являются атомарным
снимком файловой системы: запись профиля или очистка во время обхода может
дать временно неполный результат. При ошибке отображается последний полный
замер с пояснением; частичный объём не выдаётся за полный размер Orbit.

`node --test tests/service-resources.test.mjs tests/release-manager.test.mjs`
`pnpm exec next build --webpack`
`node --test tests/service-resources-api.test.mjs tests/release-manager-api.test.mjs`
`pnpm typecheck`
