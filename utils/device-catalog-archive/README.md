# Версии каталога

JSON-файлы опубликованных версий неизменяемы. При изменении шаблона:

1. Сохранить предыдущий каталог здесь и оставить его в `archivedCatalogs` в `deviceCatalog.js`.
2. Присвоить текущему каталогу новый `version`, изменённому шаблону — новый `revision`.
3. Добавить снимок новой версии в архив и зарегистрировать его до публикации.
4. Запустить `tests/profile-preview.test.mjs` и `tests/device-catalog.test.mjs`.

Повторное использование версии с другим содержимым останавливает загрузку каталога.
Сохранённые паспорта проверяются по своей версии, включая исходные веса и порядок моделей.
Архив не реконструирует версии, которых нет в исходниках; неизвестная версия считается ошибкой.
При расширении набора моделей настройки весов новых профилей требуют отдельного обновления.

## android-catalog-2026-10-v2

Опубликован 2026-10-14. Шесть новых моделей Android 14 добавлены к четырём
сохранённым идентификаторам; ревизии существующих шаблонов повышены до 2.
Сумма исходных весов — 1000, Pixel 7 — 10, S23 Android 14 — 85. Веса задают
распределение генератора, а не статистику рынка. Android 15 в этой версии не
добавлен: набор соответствует предоставленному списку Android 14.

Формат Orbit сохраняет поля `version`, `model`, `os`, `renderScreen`, `browser`;
добавлены `publishedAt`, аппаратные `arch`/`bitness` и отдельный `webglLimits`.
Архитектура физического устройства не переносится в Android Client Hints: их
architecture/bitness остаются пустыми по правилам действующего адаптера.
Redmi Note 12 4G использует Adreno 610 по спецификации Xiaomi. Варианты с 6 ГБ
сохраняют deviceMemory=4 согласно существующему правилу округления Orbit.

Лимиты текстур, кубических текстур, renderbuffer, viewport и атрибутов вершин
копируются в новые паспорта и применяются к WebGL 1/2 документов и фреймов.
Это значения эмуляции, без замеров физических устройств и без изменения
аппаратных возможностей Chromium. Профили MobileProxy не наследуют локальные
лимиты; сохранённые v1 паспорта не дополняются ими. Проверка браузера измеряет
лимиты обеих версий WebGL, а карточка профиля показывает заявлено/измерено.

Сохранённые веса старого каталога читаются с нулевыми весами новых моделей,
чтобы не менять пользовательское распределение неявно. При публикации v2
на рабочем сервере отдельно применяются запрошенные веса из текущего каталога
с повышением fingerprintDistributionRevision; старые паспорта не изменяются.

Проверки: `tests/device-catalog.test.mjs`, `tests/device-catalog-v2.test.mjs`,
`tests/profile-preview.test.mjs`, `tests/android-reference.test.mjs`,
`tests/fingerprint.test.mjs`, после сборки `tests/device-catalog-ui.mjs`.

## Уточнение адаптера local-v6 после аудита

Архивные JSON v1/v2 не менялись. Новые паспорта local-v6 используют пустую
`architecture` и `bitness: "64"` из шаблона; описание пустой разрядности выше
относится к адаптеру на момент публикации каталога. Лимиты GPU также доступны
в `fingerprint.gpu`, синхронно с `videoCard`/`webglLimits` рабочего адаптера.
Сохранённые паспорта не дополняются новыми полями.
